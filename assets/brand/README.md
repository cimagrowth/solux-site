# assets/brand/

Corona — the Solux mark. **Final. Never redraw, redesign or approximate it.**

Real vector geometry: a variable-weight ring whose stroke thickens where light
falls and thins into shadow, running deep indigo → indigo → warm gold, with a
small core. *Sol* + *lux* — light rimming a sphere. It reads as a cell and as a
sunrise, and it holds at 20px.

## The one deliberate pairing rule

On the **marketing site** the mark pairs with "Solux" set in **Archivo**, the site's
own display face (wdth 112, weight 660, tracking 0.005em) — *not* the DM Sans
lockup, whose wordmark clashes with the site typography. The DM Sans lockup is
correct everywhere else.

Mark sizes: **25px** in the nav, **27px** in the footer, **22px** under 700px.
